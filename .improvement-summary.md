# Improvement Summary

## What was changed

### 1. Created missing audit prompt files

The `.opencode-reviewer.yml` config references `error-handling-resilience` and `performance-efficiency` audit categories, but no corresponding prompt files existed under `prompts/audit-categories/`. This meant those audit categories would silently degrade at runtime.

**Created:**
- `prompts/audit-categories/error-handling-resilience.md` — Covers error boundaries, graceful degradation, retry/backoff patterns, logging hygiene, and transaction safety. Mirrors the project's actual resilience patterns (withRetry, CircuitBreaker, graceful degradation).
- `prompts/audit-categories/performance-efficiency.md` — Covers N+1 queries, caching strategy, async/concurrency patterns, bundle efficiency, and memory/resource management.

Both follow the existing prompt template structure (title, task description, "What to Check" subsections, JSONL output format, severity guide).

### 2. Updated documentation to align with actual project structure

- **`.agents/AGENTS.md`**: Fixed the project structure section to accurately describe `prompts/audit-categories/` as the built-in prompt location and `.audit-prompts/` as an optional override directory.
- **`.agents/skills/opencode-reviewer-development/SKILL.md`**: Updated the audit prompts section header, paths, and instructions to reflect where prompts actually live and how the fallback mechanism works.
- **`.agents/skills/opencode-reviewer-fixing/SKILL.md`**: Fixed a stale path reference from `.audit-prompts/` to `prompts/audit-categories/`.
